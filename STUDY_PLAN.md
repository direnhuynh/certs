# 14-Day Study Plan

Budget: 2–3 hours per day. Domain weights come from third-party summaries of the exam blueprint. Confirm them in the official exam guide.

| Domain | Weight | Lab |
|---|---|---|
| Applications and Integration | 33.1% | `labs/01-applications` |
| Model Selection and Optimization | 16.8% | `labs/02-model-selection` |
| Agents and Workflows | 14.7% | `labs/03-agents` |
| Prompt and Context Engineering | 11.0% | `labs/05-prompt-context` |
| Tools and MCPs | 10.6% | `labs/04-tools-mcp` |
| Security and Safety | 8.1% | `labs/06-security-claude-code-evals` |
| Claude Code | 3.1% | `labs/06-security-claude-code-evals` |
| Eval, Testing, and Debugging | 2.6% | `labs/06-security-claude-code-evals` |

## Week 1 — Build

- [ ] **Day 0** — Confirm eligibility (partner company email). Download the official exam guide. Set up `.venv` and `.env`.
- [ ] **Day 1** — Lesson 1.1 Messages API basics (`labs/01-applications/01_basic_message.md` → `.py`).
- [ ] **Day 2** — Lessons 1.2 Streaming and 1.3 Errors and retry.
- [ ] **Day 3** — Lessons 1.4 Batches and 1.5 Structured output.
- [ ] **Day 4** — Applications review: vision, PDF input, Files API, citations (docs, see `labs/01-applications/README.md`). 20 practice questions.
- [ ] **Day 5** — Lessons 2.1 Choosing a model and 2.3 Token counting.
- [ ] **Day 6** — Lessons 2.2 Prompt caching and 2.4 Effort and thinking.
- [ ] **Day 7** — Lesson 3.1 Tool use and the manual agent loop. Read "Building effective agents".

## Week 2 — Breadth, then practice

- [ ] **Day 8** — Lesson 3.2 Tool Runner, agent architectures, workflow patterns.
- [ ] **Day 9** — Lesson 4.1 Tool design and MCP server; connect it to Claude Code.
- [ ] **Day 10** — Lesson 5.1 Prompt and context engineering.
- [ ] **Day 11** — Lessons 6.1 Security, 6.2 Evals, 6.3 Claude Code (hands-on).
- [ ] **Day 12** — Mock exam 1 (timed, 120 min). Review every miss.
- [ ] **Day 13** — Re-study the two weakest domains. Mock exam 2.
- [ ] **Day 14** — Mock exam 3. Read `notes/cheatsheet.md` and `notes/mistakes.md`. Sit the exam on day 14 or 15.

## Target scores

Book the exam when you score **80% or more** on two mock exams in a row. The pass mark is 720/1000, so 80% gives you a safety margin.
