## How to take a test

1. Set a 120-minute timer. No notes, no docs.
2. Write one letter after each `**Answer:**`.
3. Ask Claude: `review practice/mock-test-01.md`.
4. Claude grades the test against the key and reports:
   - your score and pass/fail against the 73% and 80% targets
   - your score per domain
   - an explanation for each wrong answer
5. Log each miss in `notes/mistakes.md` and your score in `mock-exams.md`.

Suggested order: test 1 on day 12, test 2 on day 13, test 3 on day 14. Use tests 4–5 for extra rounds or for re-checking weak domains.

These are practice questions written from public exam topics. They are not real exam questions.
